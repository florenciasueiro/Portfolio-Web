# Portfolio premium de Flor

Portfolio profesional construido con React 19, Vite, TypeScript, Tailwind CSS, Framer Motion, Lenis, React Three Fiber, React Hook Form y Zod.

## Antes de publicarlo

Reemplazá estos datos de ejemplo:

- `tuemail@ejemplo.com` en `src/sections/Contact.tsx`.
- Los enlaces `#` de LinkedIn y GitHub en `src/sections/Footer.tsx`.
- Agregá los repositorios reales en `src/constants/data.ts` cuando quieras mostrar botones de GitHub.

## Desarrollo local

```bash
npm install
npm run dev
```

## Publicar gratis en Vercel

1. Creá un repositorio nuevo en GitHub.
2. Subí el contenido de esta carpeta al repositorio.
3. Abrí https://vercel.com/new e iniciá sesión con GitHub.
4. Seleccioná **Import** junto al repositorio.
5. Vercel reconocerá Vite automáticamente.
6. Presioná **Deploy** sin cambiar la configuración predeterminada.

Cada cambio posterior que subas a la rama principal se publicará automáticamente.
